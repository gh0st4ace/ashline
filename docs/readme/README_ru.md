## Обязательно к прочтению

**[methodology.md](../methodology.md)** — ядро репозитория. Четыре режима отказа,
стоившие часов каждый, и правила, которые из них выросли. Остальные документы
описывают *что* установлено; этот — *почему так*, и почему иначе нельзя.

**[architecture.md](../../docs/architecture.md)** — два неочевидных факта, которые ломают
наивную настройку:

- Скилы грузятся из **пяти** корней, а не трёх. Считать только настроенные —
  ошибка на треть каталога.
- Каталог из 34 MCP-сервера — это **меню**, а не конфигурация. Работают 6.

**[troubleshooting.md](../troubleshooting.md)** — замеренные режимы отказа с
исправлением. `verify-setup.ps1` может напечатать зелёный OK, описывая поломку;
это задокументировано, а не спрятано.

## Быстрая шпаргалка

```powershell
.\install.ps1 -DryRun            # план установки, ничего не пишет
.\scripts\verify-setup.ps1      # тулчейн и обвязка, всегда код 0
py -3 .\scripts\doctor.py       # рантайм, коды 0/1/2 — единственный CI-гейт
.\scripts\update-awgs.ps1       # обновить коллекции и перелинковать
```

Слэш-команды: `/verify` `/doctor` `/stack` `/refresh` `/re <path> [addr]`
`/state`.
